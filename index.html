Multi-Class Skin Lesion Detection — Engineering Journey

From raw Kaggle datasets to a trained Faster R-CNN ResNet50 FPN detection system

This document records how the project was built, not just the final model. The goal was a multi-class skin lesion detection system — one that localises each lesion with a bounding box and assigns a specific disease label. Classification alone is insufficient because a clinician needs to know where the model is looking.

Motivation

  • Manual review of dermoscopic images requires specialist time and is hard to scale.
  • A detector highlights lesion regions and proposes a disease category for triage — not just a global label.

Dataset Processing Pipeline

The backbone of this project

Work began with publicly available Kaggle skin-lesion datasets. Sources evolved from a coarse binary problem (Benign vs Malignant) to a 10-class taxonomy — but each source had different folder structures, class IDs, and annotation formats. This pipeline turns those heterogeneous archives into one clean Faster R-CNN training set.

# Parse to absolute pixel coords
def parse_yolo_label(path, img_w, img_h):
    for line in open(path):
        cls, xc, yc, w, h = map(float, line.split())
        x1, y1 = (xc-w/2)*img_w, (yc-h/2)*img_h
        x2, y2 = (xc+w/2)*img_w, (yc+h/2)*img_h
        yield int(cls), x1, y1, x2, y2

Image Preprocessing and Data Cleaning

Before training, the raw dataset went through multiple preprocessing and quality checks to improve data consistency and reliability. Each step was applied sequentially to ensure only clean, well-annotated samples reached the model.

1 · Duplicate Image Removal

Duplicate images were identified and removed to avoid repeated samples affecting model learning. Identical images hash to the same value, making hash comparison a fast and reliable deduplication method.

# Hash-based duplicate detection
from hashlib import md5
seen = {}
for img_path in image_dir.glob("*.jpg"):
    h = md5(img_path.read_bytes()).hexdigest()
    if h in seen:
        img_path.unlink()   # remove duplicate
    else:
        seen[h] = img_path

2 · Blur and Quality Check

Low-quality and blurred images were detected and removed because unclear lesion details can affect detection performance. Laplacian variance is a reliable proxy for image sharpness — a low value indicates a blurry image.

# Blur detection via Laplacian variance
import cv2
BLUR_THRESHOLD = 80.0
for img_path in image_dir.glob("*.jpg"):
    img = cv2.imread(str(img_path), cv2.IMREAD_GRAYSCALE)
    var = cv2.Laplacian(img, cv2.CV_64F).var()
    if var < BLUR_THRESHOLD:
        print(f"BLURRY — removing: {img_path.name}")

3 · Image-Label Verification

Every image was verified to have a corresponding annotation file. Missing annotation pairs were identified before any further processing step to prevent silent data loss during training.

# Check every image has a matching label file
missing = []
for img_path in image_dir.glob("*.jpg"):
    lbl = label_dir / img_path.with_suffix(".txt").name
    if not lbl.exists():
        missing.append(img_path.name)
print(f"Missing labels: {len(missing)}")

4 · Annotation Validation

Annotation files were checked to ensure they followed the correct YOLO format and contained valid bounding box values. Boxes with coordinates outside the normalised 0–1 range were flagged as corrupt entries.

# Validate bounding box values in label files
for lbl_path in label_dir.glob("*.txt"):
    for line in open(lbl_path):
        parts = line.split()
        cls, xc, yc, w, h = int(parts[0]), *map(float, parts[1:])
        if not (0 <= xc <= 1 and 0 <= yc <= 1 and w > 0 and h > 0):
            print(f"INVALID box in {lbl_path.name}: {line.strip()}")

5 · Dataset Distribution Check

Class distribution was verified after preprocessing to ensure all 10 disease categories were correctly included. Any class with zero samples would be silent during training, so this check was mandatory before starting model training.

# Count annotations per class
from collections import Counter
counts = Counter()
for lbl in label_dir.glob("*.txt"):
    for line in open(lbl):
        counts[int(line.split()[0])] += 1
for cls_id, name in ID_TO_NAME.items():

Finding and Fixing the Missing Pigmented BK Class

Symptom

During dataset validation, class distribution showed pigmented_bk : 0. The processed training set contained no Pigmented Benign Keratosis samples, so the detector could not learn that class.

That was inconsistent with the raw data: Pigmented BK images existed, and annotation files existed. The class was disappearing between source folders and the merged set.

Investigation

Checks covered dataset folders, image–label pairs, class mappings, and the merge scripts:

  1. Confirmed raw Pigmented BK images were on disk.
  2. Confirmed matching YOLO label files existed.
  3. Compared image stems to label stems for naming mismatches.
  4. Traced merge logs for skipped “missing label” paths.
  5. Walked class-id remapping to rule out a silent remap to another class.
# Audit class distribution across processed labels
from collections import Counter
counts = Counter()
for lbl in label_dir.glob("*.txt"):
    for line in open(lbl):
        counts[int(line.split()[0])] += 1
for cls_id, name in ID_TO_NAME.items():
    print(f"{name:<20}: {counts.get(cls_id, 0)}")

Root cause

Image and label mapping was not handled correctly during dataset merging. Some sources nested labels (for example labels/labels/Train) while the merge logic assumed a flat label directory. Pigmented BK pairs were skipped and never copied into the processed dataset.

Fix

  • Corrected image–label mapping, including nested label search paths.
  • Updated the merge pipeline so pairs are copied together and collisions get a source prefix.
  • Regenerated the processed dataset.
  • Repeated YOLO → COCO conversion.
  • Verified class distribution again before training.

Why Faster R-CNN?

The core constraint

The project needs both a location and a disease name per lesion. A pure image classifier emits a single global label — no box, no spatial evidence. That ruled it out as the primary system.

A classifier cannot answer where the lesion is. There is no bounding box to inspect, overlay, or evaluate with COCO AP.

Why two-stage detection?

Localization Faster R-CNN is built around region proposals and box regression — every output is a spatial prediction, not a global logit.
Precision Two-stage detectors produce tighter boxes than single-stage models or CAM overlays, which matters for precise lesion boundaries.
Transfer learning COCO-pretrained ResNet50 backbone gives strong low-level features even when the skin-lesion corpus is modest in size.
Multi-scale (FPN) Feature Pyramid Network fuses P2–P6 feature maps so small and large lesions are both proposable without resizing tricks.

Chosen model

Faster R-CNN ResNet50 FPN v2 (fasterrcnn_resnet50_fpn_v2) — COCO-pretrained backbone and RPN, with the classification head replaced for 11 outputs (background + 10 diseases):

from torchvision.models.detection import fasterrcnn_resnet50_fpn_v2
from torchvision.models.detection.faster_rcnn import FastRCNNPredictor

model = fasterrcnn_resnet50_fpn_v2(weights="DEFAULT")

# Replace head: background + 10 lesion classes
in_features = model.roi_heads.box_predictor.cls_score.in_features
model.roi_heads.box_predictor = FastRCNNPredictor(in_features, num_classes=11)

Architecture — component by component

Input Image  (H × W × 3)
        ↓
ResNet50 Backbone  →  C2, C3, C4, C5 feature maps
        ↓
FPN  →  P2–P6  (multi-scale lateral connections)
        ↓
RPN  →  objectness score + Δbox per anchor  (proposals)
        ↓
ROI Align  →  7×7 pooled features per proposal
        ↓
FC layers  →  class logits + box deltas
        ↓
{ box [x1,y1,x2,y2],  label,  score }
ResNet50 Hierarchical visual features. Pretrained on ImageNet via COCO weights — low-level edges and textures transfer well to dermoscopy.
FPN Lateral + top-down connections produce P2–P6. Larger feature maps (P2) cover small lesions; P5/P6 cover large ones.
RPN Slides anchors over every FPN level. Outputs objectness (lesion vs background) and a rough box for each proposal passed to ROI heads.
ROI Align Bilinear interpolation — avoids the quantisation artefacts of ROI Pooling. Produces fixed 7×7 feature crops per proposal.
FC predictor Two fully-connected layers output final class scores (11-way softmax) and box regression deltas simultaneously.

# Core training loop
for epoch in range(NUM_EPOCHS):
    model.train()
    for imgs, targets in train_loader:
        imgs    = [i.to(device) for i in imgs]
        targets = [{k: v.to(device) for k,v in t.items()} for t in targets]

        loss_dict = model(imgs, targets)          # Faster R-CNN returns loss dict
        loss = sum(loss_dict.values())

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

    if loss < best_loss:
        best_loss = loss
        torch.save(model.state_dict(), CKPT_PATH)

The best checkpoint is selected by average train/validation loss and reused for test prediction and COCO evaluation.

Evaluation Results

Evaluation pipeline

After training, the detector is run on the unseen test split. Predictions are written to prediction_results.json and scored with pycocotools (Average Precision across IoU thresholds and recall).

Headline metrics

mAP@0.5:      60.2%
mAP@0.5:0.95: 34.4%

How to read these numbers

mAP@0.5 rewards a prediction when the box overlaps ground truth by at least 0.5 IoU and the class is correct. mAP@0.5:0.95 averages AP from IoU 0.5 to 0.95 and is stricter on localization. Together they measure whether lesions are found and how well boxes align—not image-level accuracy.

Observation

The model shows strong detection performance for classes such as Malignant, Benign, and Vascular Lesions. Lower performance was observed for Basal Cell Carcinoma and Dermatofibroma, indicating the need for additional data balancing and targeted improvements.

Evaluation Method: Class-wise recall was calculated by comparing predicted detections against ground-truth annotations on the unseen test dataset.

Future Improvements

Next engineering work

  • Balance underrepresented classes (more samples or controlled oversampling).
  • Class-aware augmentation (geometric and photometric) without breaking box coordinates.
  • Hyperparameter search: learning-rate schedule, anchors, NMS thresholds.
  • Targeted collection and loss re-weighting for weaker disease categories.
  • External clinical validation on a held-out source the merge pipeline never saw.
